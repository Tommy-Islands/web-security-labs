# Access Control：予測しにくいURLで公開された管理機能の認可不備

## 1. 検証概要

| 項目 | 内容 |
|---|---|
| 学習プラットフォーム | PortSwigger Web Security Academy |
| 対象ラボ | Unprotected admin functionality with unpredictable URL |
| 分野 | Access Control |
| 難易度 | Apprentice |
| 検証日 | 2026-11-15 |
| 使用ツール | ブラウザの「ページのソースを表示」機能とアドレスバー |
| 検証結果 | Solved |

管理画面へのリンクをJavaScriptで表示しない構成で、サーバー側の認可が働いているかを確認した。未ログインの状態で管理画面が表示され、ラボ内のユーザー削除が成立した。

[対象ラボ](https://portswigger.net/web-security/access-control/lab-unprotected-admin-functionality-with-unpredictable-url)

## 2. 実務上の攻撃シナリオと想定被害

ECサイトの管理機能で同様の認可漏れがある場合、外部の利用者が管理機能に到達し、権限が必要な操作を実行できる可能性がある。対象がアカウント削除機能なら、正規ユーザーがログインできなくなり、注文履歴などへのアクセスやサポート対応にも影響する。

ラボで確認した影響は、未ログイン時の管理画面の表示と、テストユーザー `carlos` の削除。ECサイトでの業務影響は想定であり、ラボで計測した被害には含めていない。

## 3. 検証手順と観察結果

| 観察対象 | 確認した事実 |
|---|---|
| トップページのソース | インラインJavaScriptの条件分岐に管理画面のパスが含まれていた |
| トップページの画面 | `isAdmin` が `false` の場合、管理画面へのリンクはDOMに追加されなかった |
| 管理画面への直接遷移 | 未ログインの状態で管理画面が表示された |
| ラボ内のユーザー管理 | テストユーザー `carlos` の削除が成立し、LAB Solvedを確認した |

## 4. 実証HTTPに代わる観察記録

### ソースの該当箇所

トップページ内の `<script>` に、`isAdmin` が真のときだけ管理画面へのリンクをDOMに追加する条件分岐があった。リンクの表示が抑止される状態でも、配信されたソースにはリンク先のパスが含まれていた。ここでは条件分岐の挙動を要約し、具体的なパスは伏せた。

### 管理画面へのアクセス結果

直接遷移すると未ログインのまま管理画面が表示された。証拠はブラウザ上の画面遷移とラボの状態表示。HTTPのステータス、ヘッダー、レスポンス本文の生データは採取していない。

## 5. 根本原因

管理画面の表示とユーザー削除で、サーバー側の管理者権限チェックが有効に適用されていなかった。JavaScriptの `isAdmin` はリンクの表示条件に使われ、サーバーが管理者権限を確認する仕組みを提供しない。管理画面のパスがソースに含まれていたことは、リンク先が分かった経緯に当たる。未認可の表示と削除が成立したことが、アクセス制御上の問題を示す。

## 6. 防止策と検知策

- **認可をサーバー側で強制する。** 管理画面の表示と削除のそれぞれで、認証済みの利用者に操作に必要な権限があるか確認する。未ログイン時と権限不足時はアクセスや処理を拒否する。
- **共通の認可処理を適用する。** 管理用ルートは原則拒否とし、許可条件を明示する。新しい画面やAPIも同じ認可処理の対象にする。
- **権限別に回帰テストする。** 未ログイン、一般ユーザー、管理者について、画面の表示と操作の実行を個別に確認する。拒否された削除リクエストでデータが変化していないことも検証する。
- **管理操作を監査する。** 実行者または未認証の別、対象、操作、許可・拒否、処理結果を記録する。未認証セッションでの管理機能へのアクセス成功や、短時間に集中する削除を検知対象にする。

## 7. 未検証事項

- 生のHTTPリクエスト・レスポンス、ステータスコード、Cookieの詳細
- サーバー側のソースコードと、認可処理が適用されなかった実装箇所
- 一般ユーザーでログインした状態での挙動、削除以外の管理機能への影響

| 問 | テーマ | 回答 | 判定 | 自信度 |

| 2 | リンク非表示とサーバー側認可の違い | C：リンクの表示制御と、権限に基づくリクエストの許可・拒否 | 正解 | あり |
